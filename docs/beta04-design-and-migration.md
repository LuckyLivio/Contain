# v0.4.0-beta.1 桌面迁移与验收约定

本轮把普通用户入口迁移为 WPF + WPF UI，仍运行 `Contain.Viewer.exe`。
目标流程是“选择 EXE → 明确点击开始 → 保存 → 查看文件操作 → 下次找回”。
不修改 ETW、归因算法、CLI 协议或 SQLite schema，不增加卸载、删除、回滚、
默认安装路径库或后台采集。Beta.10 的标签、资产、旧报告和个人数据库保持不变。

这份文件规定实现与验证契约；**不是已通过的 Windows 验收报告**。
初始记录时，新 WPF 产品的原生运行、截图和最终包验收均待完成。
后续结果必须记录实际源码、包哈希、运行编号及失败项，不能引用旧 WinForms
的通过结果来声明新界面已验收。

最终结果：新包已通过 [M13 完整原生验收](beta04-release.md)，实际截图及前后对照见[截图记录](beta04-screenshots.md)。本文件保留原先约定，不改写各次失败结果。

## 统一视觉与交互

- 浅色主题优先：柔和中性主背景、清晰内容面、克制青绿强调色；状态颜色之外
  同时提供文字，不把警告、失败或 Unknown 统一染成成功。
- 使用 WPF UI 的 `FluentWindow`、`TitleBar`、`NavigationView`、`Button` 与
  `ContentDialogHost`；保留拖动、系统菜单、缩放、最小化、最大化与关闭。
- 左侧紧凑导航以“我的记录”“新建记录”为主，外部库和关于置于次要区域。
  详情属于已选记录；返回列表不丢失会话身份。
- 正文约 14 DIP，页面标题 22–26 DIP；系统 UI 字体及中文回退，不随包复制字体。
  采用 4/8 DIP 间距，主要容器 16–24 DIP 内边距、8–12 DIP 圆角。
- 信息通过留白、文字层次及轻微背景差分组；列表清晰对齐，避免粗网格、巨大
  标题、同权重按钮墙和无意义空白。一个任务区域只有一个主要操作。
- 使用内嵌的 MIT Fluent System Icons；图标配文字，可访问名称与稳定
  `AutomationId`。保留焦点、悬停、按下、禁用、选中等组件状态。
- 窄窗收起导航，表单和详情可重排或滚动；不设置超出实际工作区的最小尺寸。
  长路径省略时可查看、复制完整内容；分页及主要操作仍应可见可用。
- 空记录引导新建，加载有状态，错误有可执行下一步，无匹配时可清除搜索。
  高级设置和技术详情默认折叠，但必要覆盖限制直接可见。

## 功能迁移清单

下表是必须保留的行为，不要求保留 WinForms 控件结构或旧测试数量。
“验证”列定义新实现的检查；执行情况另记，不能在尚未运行时标为通过。

| 旧功能 / 行为依据 | 新入口与契约 | 验证 |
| --- | --- | --- |
| `InstallForm` 选择安装器、名称建议 | 新建记录：选择 EXE、显示文件名、展开完整路径、允许更换；选择本身不启动 | 文件选择取消无进程；未点开始无运行；名称可修改 |
| 默认跟随安装器、已验证直接子进程 | 默认记录方式保持跟随；普通流程无需目录和数据库选择 | 实包通过 GUI 安装夹具；独立核对父子写入和无关写入 |
| `PersonalRecords` 默认库与重开 | 默认保存“我的记录”，沿用既有用户库位置与格式 | 隔离个人库首次空态、保存、不同工作目录冷启动找回 |
| 外部库只读 | 次要入口“打开外部记录库”，明确只读来源 | 查询前后文件指纹相同；失败不重建 DB，不删除 WAL/SHM |
| UUID 会话选择、同名记录 | 列表显示名称/时间/状态，实际操作绑定完整 UUID | 同名快速切换与迟到结果；准确 UUID；旧结果/旧错误不覆盖新选择 |
| 安装预检与任务保护 | 开始前在当前页自然预检；运行区展示阶段、耗时、实际进展 | 权限/来源失败不启动；重复开始、任务切换、关闭保护 |
| 结束回调与保存读回 | 保存确认后打开本次准确会话并提示“记录已保存，可以查看文件操作” | 安装器结果、采集停止、保存和覆盖分别核对；退出重开解释一致 |
| 概览 / `OverviewPresentation` | 详情顶部先显示安装器结果、保存状态、覆盖限制 | exit 0、非零、未结束、未确认保存、Incomplete、缺失统计分别表达 |
| 前后状态差异 / 历史 | “状态对比”分区 | 跟随模式明确无前后基线；缺失不显示为 0；手动模式保留已有差异 |
| 文件事件与解释 | “文件操作”，事件行、选中解释、复制 ID、展开原始依据 | 会话/事件一致；完整 ID、原始操作、JSON 和依据可核对 |
| `SearchVerification` 跨页搜索 | 当前会话搜索、结果总数、分页、清除 | 130 条事件 / 53 条匹配夹具；准确 ID、顺序、无重复遗漏 |
| `ReportExporter` | “导出本页报告” | 当前页、准确会话和选中解释；取消/失败/目标存在保护 |
| `SearchReportExporter` | “导出全部 N 条匹配结果” | 固定开始时会话/查询/快照；导出途中改变页面不混入新条件；完整顺序 |
| 手动目录与全部高级配置 | 新建记录的折叠高级设置：跟随/指定目录、名称、保存位置、逐行参数、HKCU 注册表、快照模式、整理/排空时限 | 沿用 `InstallRequest.Validate` 与 `ArgumentList`；无 shell 拼接；原互斥和上限仍有效 |
| 进度 / 错误原文 / 复制诊断 | 任务区域简明状态，技术详情保留完整诊断与复制摘要 | 本地续计不冒充实际进展；失败类型、阶段、原文和缺失值保留 |
| 接收/候选/交付/保存损失 | 技术详情按原口径分项 | 不重复加总；旧会话缺字段显示“未提供”；已结束且读回成功不继续提示等待 |
| 布局与首用 | 三页同一设计，紧凑窗与键盘操作 | 实际截图审阅、可见矩形、可操作性、焦点、滚动和长路径 |

## 数据、异步和证据边界

复用 `CoreClient`、`InstallClient`、`PersonalRecords`、`OverviewPresentation`、
`ReportExporter`、`SearchReportExporter` 及相邻协议模型，适度分离控件耦合。
新 UI 不增加直接写 SQLite 的实现；打开历史记录不启动安装或修改记录。
查询、解释和导出异步执行；切换会话、页码或查询后取消或丢弃旧请求，取消不显示
为新页面错误。选中事件、复制、解释和导出绑定同一会话及事件身份。

持续读取采集进程 stdout/stderr，沿用参数列表、存储/队列/退出边界。关闭窗口
不能误杀安装器或绕过保存；记录任务明确结束后才清理其订阅和句柄。
测试只使用有标识的隔离目录与数据库，不访问开发者个人库。

退出码 0 只表示安装器返回结果，保存成功不表示覆盖完整；`Unknown` 是证据不足，
不是危险标记。`High` 是有依据的执行进程关联，不是最终文件所有权或安全删除许可。
历史缓存名称不等于已验证当前路径。没有基线、未提供统计与实际零值分别表达。
已有丢失后抑制升级规则不变。

## 预先确定的验证安排

1. **受控逻辑回归**：以同步点/确定状态序列验证实际 ViewModel/客户端路径，
   包含同名会话迟到结果、取消后迟到错误、重复开始、合法控件过渡后准确会话、
   持续缺失/错误会话/产品提前退出/非预期 UIA 异常明确失败。复用既有展示语义
   和导出保护断言，新增测试不能仅复制辅助函数实现。
2. **首次 Windows 页面检查**：在隔离样本下运行打包的新 WPF EXE，检查三个
   页面、空态、错误态、紧凑布局与 AutomationId。实际查看截图后修正明显问题。
   样例标注为样例，不冒充 ETW 采集；此阶段不宣称最终包通过。
3. **冻结候选、完整验收一次**：记录包哈希、UI/核心/测试源码、SDK/运行时和
  资源配置后，用这份包完成个人库、外部只读库、同名会话、130/53 搜索导出，
   再通过默认 GUI 流程执行一次真实夹具安装。核对独立父/直接子进程成功写入、
   无关进程不误归属、准确会话、事件 ID、完成依据、保存读回、解释一致、正常
   退出及不同工作目录冷启动。不能用 Beta.10 的 WinForms D6 替代。
4. **失败处理**：保留每次计划、结果、失败类型/阶段/固定控件标识、截止时间
   分项与进程状态。先针对现场修复再决定复验；不无条件重跑挑绿、不加超时，
   不因合法过渡而吞掉持续缺失或非预期异常。UI 布局微调只复验受影响视觉；
   最终程序变化须有适用于最终包的完整集成证据。
5. **发布核验**：依赖许可/锁文件和仓库质量检查通过，PR 正常合并，main 必需
   检查通过；发布实际验收对象并回下载核对 SHA-256、包内程序身份及文件清单。
   只清理安全合并且无独有成果的任务分支。

核心二进制未变时复用 Beta.10 D4 的有界采集证据；不机械重复历史压力矩阵、
32 次研究或所有安装器测试。新 UI 与 CLI 的真实 Windows 集成必须另行完成。
